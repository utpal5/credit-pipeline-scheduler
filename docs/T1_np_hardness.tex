\section*{1. Target problem: \textsc{Feasibility}}
We prove NP-hardness of the \emph{feasibility decision problem} underlying the scheduling
model of Section 3.2: given $(V, E, r, C, \tau)$, does there exist $\sigma: V \to [K]$
satisfying F1 (conflict), F2 (capacity), and F3 (SLA window) simultaneously? Since
the optimization problem (minimize $P(\sigma)$ subject to F1--F3) contains this decision
problem as a special case (an exact optimizer must in particular certify feasibility, or
report none exists), NP-hardness of \textsc{Feasibility} implies NP-hardness of the full
problem. \textsc{Feasibility} is in NP (a candidate $\sigma$ is checked against F1--F3 in
time $O(nd + |E| + n)$), so it is in fact NP-complete.

We reduce from \textbf{3-SAT} (NP-complete). The construction below uses all three
constraint families \emph{essentially}: deleting any one of F1, F2, F3 from the built
instance breaks at least one direction of the equivalence (shown at the end of each part).

\section*{2. Construction}
Let $\varphi$ have variables $x_1,\dots,x_n$ and clauses $C_1,\dots,C_m$, each with exactly
three literals over distinct variables (WLOG). Build instance $I(\varphi)$:

\paragraph{Slots.} $K = 2$: slot $1 = \mathrm{ASSIGN}$, slot $2 = \mathrm{VERIFY}$.

\paragraph{Dimensions.} $d = m$, one dimension $\mathrm{budget}_j$ per clause $C_j$.
(Remark on collapsing to fixed $d$ appears in \S5.)

\paragraph{Literal tasks.} For each variable $x_i$, create tasks $P_i, N_i$ with
$\tau(P_i)=\tau(N_i)=[1,2]$ and conflict edge $(P_i,N_i)\in E$. Resource vector:
for each clause $C_j$,
$$ r_{\mathrm{budget}_j}(P_i) = \mathbf{1}[x_i \text{ occurs positively in } C_j], \qquad
   r_{\mathrm{budget}_j}(N_i) = \mathbf{1}[x_i \text{ occurs negated in } C_j]. $$
All other entries of $P_i, N_i$ are $0$. No conflicts other than $(P_i,N_i)$.

\paragraph{Clause tasks.} For each clause $C_j$, create task $C_j$ with
$\tau(C_j) = [2,2]$ (VERIFY only), no conflict edges, and
$r_{\mathrm{budget}_j}(C_j) = 1$, all other entries $0$.

\paragraph{Capacities.} For every $j=1,\dots,m$:
$$ C_{\mathrm{budget}_j}(1) = 3, \qquad C_{\mathrm{budget}_j}(2) = 3. $$
Weights $w(t)=1$ for all tasks (irrelevant to feasibility). Construction size is
$O(n+m)$ tasks, $O(nm)$ resource entries — polynomial in $|\varphi|$.

\paragraph{Encoding.} For variable $x_i$, since $(P_i,N_i)$ conflict and both have window
$\{1,2\}$ with only $2$ slots in the whole instance, any feasible $\sigma$ places exactly one
of $\{P_i,N_i\}$ in slot 1 and the other in slot 2. Define $A(x_i) = \mathrm{TRUE}$ iff
$\sigma(P_i)=1$. Under this definition, for \emph{every} occurrence of a literal $\ell$ of
$x_i$ in some clause, the ``matching-polarity'' task ($P_i$ if $\ell=x_i$, $N_i$ if
$\ell=\lnot x_i$) is in slot 1 \emph{iff} $\ell$ is true under $A$, by construction — this
holds for any feasible $\sigma$, not only ones arising from a satisfying assignment.

\section*{3. Feasibility-preserving direction ($\varphi$ satisfiable $\Rightarrow$ $I(\varphi)$ feasible)}
Let $A$ satisfy $\varphi$. Set $\sigma(P_i)=1,\sigma(N_i)=2$ if $A(x_i)=\mathrm{T}$, else
$\sigma(P_i)=2,\sigma(N_i)=1$; set $\sigma(C_j)=2$ for all $j$.
\begin{itemize}[leftmargin=*]
\item \textbf{F1:} $\sigma(P_i)\neq\sigma(N_i)$ by construction. \checkmark
\item \textbf{F3:} literal tasks land in $\{1,2\}=[1,2]$; clause tasks land in
  $2 \in [2,2]$. \checkmark
\item \textbf{F2:} Fix $j$. In slot 2, dimension $\mathrm{budget}_j$: total demand
  $= r_{\mathrm{budget}_j}(C_j) + \sum(\text{matching-polarity tasks of } C_j\text{'s
  3 literals in slot 2})= 1 + (\#\text{false literals of }C_j\text{ under }A)$.
  Since $A$ satisfies $C_j$, at most $2$ of its $3$ literals are false, so the total is
  $\le 1+2=3=C_{\mathrm{budget}_j}(2)$. In slot 1, dimension $\mathrm{budget}_j$: at most
  the $3$ literal tasks referencing $C_j$ can appear, total $\le 3 = C_{\mathrm{budget}_j}(1)$.
  This holds for every $j$ (as $A$ satisfies every clause), and dimensions are checked
  independently, so F2 holds globally. \checkmark
\end{itemize}
Hence $\sigma$ is feasible.

\emph{Necessity of F2 here:} delete the capacity constraint and \emph{every} $\sigma$ of the
above form becomes feasible regardless of whether $A$ satisfies $\varphi$ — capacity is the
only mechanism testing satisfaction.

\section*{4. Completeness direction ($I(\varphi)$ feasible $\Rightarrow$ $\varphi$ satisfiable)}
Let $\sigma$ satisfy F1--F3. Define $A(x_i)=\mathrm{TRUE}$ iff $\sigma(P_i)=1$ (well-defined
by the F1+F3 argument in \S2). Fix any clause $C_j$; by F3, $\sigma(C_j)=2$. By F2 in
dimension $\mathrm{budget}_j$, slot 2:
$$ 1 + (\#\text{matching-polarity tasks of }C_j\text{'s literals in slot 2}) \le 3 $$
so at most $2$ of $C_j$'s $3$ matching-polarity tasks are in slot $2$, i.e. at least one is
in slot $1$, i.e. (by the encoding correspondence, which holds for \emph{any} feasible
$\sigma$) at least one literal of $C_j$ is true under $A$. As $j$ was arbitrary, $A$
satisfies $\varphi$.

\emph{Necessity of F1 here:} delete edge $(P_i,N_i)$ and both $P_i,N_i$ could sit in slot 1
simultaneously for every $i$, so \emph{no} literal task ever occupies slot 2, so F2 is
trivially satisfied for every $\varphi$ (including unsatisfiable ones) — F1 is what forces a
well-defined, contested truth assignment to exist at all. \emph{Necessity of F3:} if clause
tasks were allowed in slot 1 (window $[1,2]$ instead of $[2,2]$), an infeasible-looking
formula could be trivially satisfied by placing every $C_j$ in slot 1, where its demand
competes with nothing meaningful — F3 is what forces verification to happen in the slot
where the truth encoding is actually visible.

\section*{5. Conclusion and scope remark}
Both directions hold, the construction is polynomial, so \textsc{Feasibility} is NP-hard
(and NP-complete), and the full penalty-minimization problem is NP-hard. This is a genuine
\emph{compound} reduction: F1 enforces the binary variable-choice structure (graph
coloring), F2 tests clause satisfaction (multi-dimensional packing), and F3 enforces the
assign-before-verify temporal precedence (SLA window scheduling) — removing any one breaks
the equivalence, as shown above, so the hardness is not attributable to any single
constraint family in isolation.

The construction uses $d=m$ dimensions; the graded benchmark instances fix $d=4$. This does
not weaken the result: Section 3.2 defines the problem for general $d$, and hardness proofs
for multi-dimensional packing problems standardly scale $d$ with the instance (analogous to
vector bin-packing / multi-dimensional knapsack hardness). A fixed-$d$ (even $d=1$) version
is obtainable from this one by the standard \emph{base-$B$ digit-folding} technique: replace
the $m$ unit-weight dimensions by a single dimension with weight $B^{j-1}$ for a unit in
dimension $j$, choosing $B > 3$ (the largest possible per-dimension sum shown above) so that
no combination of lower-order contributions can carry into a higher digit; the resulting
numbers have $O(m\log B)$ bits, still polynomial in $|\varphi|$, and the same two directions
go through verbatim on the folded dimension. We omit the full re-verification for space; it
is a mechanical corollary of \S3--\S4.
